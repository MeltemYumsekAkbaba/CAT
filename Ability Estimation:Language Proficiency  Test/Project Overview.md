### Ability (θ) Estimation for a Computer Adaptive English Proficiency Assessment

This project demonstrates the full workflow for estimating test-taker (TT) ability (θ) for a Computer Adaptive Test (CAT). The test includes three skill domains, and examinees may take the test multiple times. Because the CAT design leads to sparse data, item parameters come from a pre-calibrated item pool and they are already on the same scale.

No assessment data is included due to confidentiality requirements. See the data dictinoary for data structure.

### Objective

Estimate:
- Overall ability (theta)
- Skill-specific ability (three subskills)
- θ per attempt for every test-taker

using:
- Rasch model (a = 1)
- Pre-calibrated difficulty parameters
- Warm’s Weighted Maximum Likelihood (WLE)
